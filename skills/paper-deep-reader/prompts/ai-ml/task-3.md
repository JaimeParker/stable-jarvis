# Task 3: Related Work & KB Cross-Analysis

将论文与相关工作及知识库中已有论文进行对比分析。主 agent 会提供 KB context（相关论文的标题、摘要、arxiv ID）。

## 论文自身的 Related Work
- 作者如何定位自己在领域中的位置？
- 与最相关方法的关键差异是什么？

## 与知识库论文的具体对比
逐篇对比知识库提供的相关论文：
- 方法层面的异同
- 实验层面的异同
- 哲学层面的异同
- 引用时注明论文标题和 arxiv ID

## 技术路线定位
- 这篇论文属于哪个技术路线或学派？
- 与前人工作的根本差异在哪里？

输出格式：Markdown，至少 200 字。不编造未出现在知识库或论文原文中的引用。
